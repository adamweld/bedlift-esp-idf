# UI icon manifest. One icon per line:
#
#   <name> <size> [source]
#
# <name>    what the UI code passes to ui_icon_draw()
# <size>    target size in px (longest side; aspect is kept)
# source    file in this folder; defaults to <name>.svg, then <name>.png.
#           Name an alias to use one source at two sizes.
#
# SVG (preferred) is rendered directly at <size>, anti-aliased for that exact
# grid. Tabler icons are drawn on a 24px grid and Material Symbols come in
# 20/24/40/48px optical sizes, so sizes matching the source grid come out
# crispest. PNG: shape in the alpha channel (or dark-on-light), downsampled.
# Colour comes from the UI code; rotation is applied at draw time.
#
# Sources: Tabler Icons (MIT), Material Symbols Outlined (Apache-2.0).
# Regenerated automatically by the build (components/ui/scripts/gen_icons.py).
